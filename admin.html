如何更新到網站

  1. 按上方「下載 data.js」。
  2. 到 GitHub 上你的 repository，點 Add file → Upload files，把 data.js 拖進去（會取代舊檔），按 Commit changes。
  3. 等 1～2 分鐘，重新整理網站就會看到更新。
